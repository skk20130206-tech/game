# justgame — 2D 우주 탐험

Canvas 2D로 그리는 탑다운 탐험 게임입니다. 행성 지표와 우주 비행, 캐릭터·11종 생명체·자원·기지·유적·시작 화면을 모두 2D로 표현합니다. WebGL이나 외부 3D 라이브러리를 사용하지 않습니다.

5개 행성, 자원 채굴, 기지 건설·업그레이드, 친구와 동행, 15개 유적, 산소·연료, 도감, 공유, 자동 저장과 7단계 튜토리얼을 지원합니다. 기존 저장 파일과 브라우저 저장 기록을 이어 쓸 수 있으며, 예전 비행 고도는 불러올 때 0으로 맞춥니다.

## 실행

```sh
npm run build
npm test
npm run dev
```

`http://localhost:8000/play`에서 게임을 실행합니다. `index.html`은 오프라인 미리보기이고, Cloudflare Worker는 `game/play.txt`와 시작 화면 패치를 조합해 서비스합니다.

## 조작

- WASD / 방향키 / 터치 패드: 이동, Shift: 가속
- 빈 땅 클릭: 이동, 드래그: 지도 둘러보기
- 휠: 확대·축소, V: 확대 / 전체 보기
- E: 채굴·교류·착륙, Q: 스캔, B: 건설
- F: 우주선 이륙·착륙, M: 성계 지도, J: 도감
- R: 연료 합성·비상 충전, X: 화면 효과 설정
- P 또는 상단 **모션 편집**: 모션 스튜디오

## 모션 스튜디오

시작 화면의 **모션 스튜디오** 또는 `/play?motion=1`에서 바로 열 수 있습니다. 곡괭이·도끼·칼의 준비 각도, 타격 시점, 전체 시간, 몸 기울기, 반동과 우주선 이륙·착륙 시간, 높이, 가속·감속, 충격, 분사를 조절합니다. 미리보기는 게임과 같은 그림·모션 함수를 사용하며, 일시정지·0.25배 재생·타임라인 탐색·1/30초 프레임 이동·좌우 반전을 지원합니다.

변경은 **게임에 적용 · 저장**을 눌러야 적용되며, 진행 중인 동작은 끝까지 기존 설정을 사용합니다. 설정은 이 브라우저의 `justgame-motion-v1`에 보관됩니다. 모션 설정 JSON 내보내기·불러오기로 다른 기기에 옮길 수 있습니다. 미리보기는 탐험을 일시정지하며 자원·연료를 소모하지 않습니다. 채집 피해와 파편·효과음은 설정한 타격 시점에 한 번만 발생합니다.

처음에는 7단계 튜토리얼을 플레이하고, 완료 화면에서 ‘본게임 시작’을 눌러 자유 탐험으로 넘어갑니다. 훈련의 월드와 진행은 `justgame-training-v1`에 함께 저장되어 새로고침 후에도 이어집니다. 처음 완료하면 훈련의 자원·집·발견을 본게임으로 가져갑니다.

본게임은 기존 `orbit-frontier-save-v1`과 같은 형식을 사용합니다. 기존 이용자는 바로 이어서 플레이하며 `?`에서 별도 튜토리얼을 다시 연습할 수 있습니다. 재연습을 마치면 원래 본게임으로 돌아갑니다.

## 파일

- `game/core.js`: 게임 규칙과 기존 저장 형식
- `game/portraits.js`: 2D 생명체·행성 일러스트
- `game/renderer-2d.js`: Canvas 2D 화면, 카메라, 이펙트, 미니맵
- `game/app.js`, `game/tutorial.js`: 조작과 튜토리얼
- `game/motion.js`, `game/motion-editor.js`: 공용 모션 계산·설정 검증과 편집 화면
- `patch/start-screen-side-ad.txt`: 2D 시작 화면

이전 3D 렌더러와 모델 파일은 이력 보관용으로 남아 있으나 게임 빌드와 Worker에서 불러오지 않습니다.
