# AdSense 준비 작업 — 2026-10-13

승인 여부를 판정하거나 보장하는 문서가 아닙니다. 사이트의 실제 변경과 계정에서 확인할 항목을 구분합니다.

## 배포 내용

- 첫 방문 흐름을 현재의 시그마 훈련 기지와 일치시킴.
- 기본 가이드와 자원·건설, 다섯 행성, 모션 편집, 저장·문제 해결에 관한 독자적인 안내를 작성. 수량과 조작을 게임 코드와 대조함.
- 최신 업데이트, 실제 운영 채널, 로컬 저장 항목과 삭제·백업 방법을 안내.
- 모든 안내 페이지는 JavaScript 없이 읽을 수 있고, 내부 링크와 목차로 연결됨.
- 페이지별 제목·설명·절대 canonical URL, sitemap, robots, HTTPS 리디렉션 제공.
- 404는 실제 404 상태와 noindex. 오류·게임·정책 페이지를 포함해 광고 실행 스크립트 없음.
- 기존 게시자 ID `ca-pub-6073295964667681`를 그대로 사용.
- Google 공식 지원 방식인 `google-adsense-account` 메타 태그와 `/ads.txt`로 소유 확인 준비.
- `ads.txt`: `google.com, pub-6073295964667681, DIRECT, f08c47fec0942fa0`.

## 계정에서 확인할 항목

1. AdSense에 등록한 실제 사이트 주소가 이 Worker를 제공하는 주소인지 확인. 다른 도메인을 등록했다면 그 도메인에서 홈·가이드·ads.txt가 직접 열려야 함. 이 작업은 도메인 또는 DNS 설정을 변경하지 않음.
2. 게시자 ID가 계정에서 제공하는 값과 같은지 확인. 사이트 연결 화면에서는 **메타 태그** 또는 **ads.txt** 확인 방식을 사용할 수 있음. 기존 광고 코드 방식만 다시 검사하면 코드가 없다는 안내가 나올 수 있음.
3. 아직 심사 전이거나 수정 요청을 받은 상태이면 사이트 화면에서 확인 후 검토 요청. 이미 심사 중이면 사이트를 삭제·재등록하지 말고 상태를 확인.
4. 광고 제공 전에 Google의 개인정보 보호 및 메시지 메뉴에서 필요한 동의 메시지/CMP를 구성. EEA·영국·스위스 맞춤 광고에는 Google 인증 CMP와 TCF 요건 확인.
5. 현재 실제 광고는 비활성 상태. 승인과 동의 설정 확인 후 별도 변경으로 콘텐츠 페이지의 적절한 위치에서만 활성화. 게임/모션/정책/문의/404/오류 페이지에는 광고를 추가하지 않는 방향을 유지.
6. 직접 제공한 이미지 등 외부 자료의 사용 권한은 운영자가 확인해야 함. 출처/라이선스를 확인하지 못한 자료에 대해 전체 권리 보유를 주장하는 문구는 추가하지 않음.

계정의 심사 사유, 등록 도메인, CMP 상태, 소유자 정보는 이 코드 작업에서 확인하지 못했습니다. 운영자 실명, 이메일, 주소, 처리기간 또는 동의 상태를 임의로 만들지 않았습니다. 기본 안내를 바탕으로 실제 운영 방식이 바뀌면 개인정보처리방침도 함께 갱신해야 합니다.
